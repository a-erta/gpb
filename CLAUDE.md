# GPB — Generative Premium Bullshitter

Satirical landing page (fictional product, no real company/person). Single static file: `index.html` (inline CSS/JS, Google Fonts only). The announcement generator runs fully client-side.

Deploy: Render static site `gpb` (workspace AMG Boat Experiences), auto-deploy from `main`, publish path `./`, no build step.

Idea for v2: "Pitch your project" mode backed by Kimi via a small server endpoint (API key only in Render env vars, never in the page).
